## 🚀 Live Demo Options

### Option 1: Local Demo
```
1. Clone: git clone https://github.com/tharunybegumpet/resolveit.git
2. Setup database: Import resolveit-db.sql
3. Start backend: cd resolveit-backend && mvn spring-boot:run
4. Start frontend: cd resolveit-frontend && npm install && npm start
5. Access: http://localhost:3000
```

### Option 2: Quick Start (Windows)
```
1. Clone repository
2. Double-click START_RESOLVEIT.bat
3. Access: http://localhost:3000
```
