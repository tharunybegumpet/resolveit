  HOW TO GET PUBLIC LINK FOR YOUR PROJECT
========================================

🎯 EASIEST METHOD: NGROK (5 minutes)
========================================

1. Download Ngrok: https://ngrok.com/download
2. Extract to C:\ngrok\
3. Sign up free: https://dashboard.ngrok.com/signup
4. Get token: https://dashboard.ngrok.com/get-started/your-authtoken
5. Run: cd C:\ngrok && ngrok config add-authtoken YOUR_TOKEN

6. Start backend: cd resolveit-backend && mvn spring-boot:run
7. Start frontend: cd resolveit-frontend && npm start

8. Create public URLs:
   Terminal 1: cd C:\ngrok && ngrok http 8080
   Terminal 2: cd C:\ngrok && ngrok http 3000

9. Copy the URLs and share!
